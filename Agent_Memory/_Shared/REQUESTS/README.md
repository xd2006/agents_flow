# Inter-Agent Requests Channel

This directory contains formal, structured requests between agents in the Agent-Flow framework.

## Request Naming & Schema
- File naming: `REQ-<AGENT_PREFIX>-<NUMBER>.md` (e.g. `REQ-AA-0001.md` for Asset-Artist requests).
- Template: [INPUT_REQUEST.md](file:///d:/mydocs/GitHub/Agent-Flow/Agents/Asset-Artist/templates/INPUT_REQUEST.md).
- Status cycle: `OPEN` -> `ANSWERED` -> `FOLLOW_UP` / `CLOSED` / `REJECTED` / `ESCALATED`.

Requests are also tracked as items on [TASK_BOARD.md](file:///d:/mydocs/GitHub/Agent-Flow/Agent_Memory/_Shared/TASK_BOARD.md).
