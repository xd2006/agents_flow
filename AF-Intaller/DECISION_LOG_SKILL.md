# DECISION_LOG_SKILL

Record consequential installation decisions in `Agent_Memory/AF-Intaller/DECISION_LOG.md` and project-wide decisions in `_Shared/DECISIONS.md` only when they affect the project.

Each record: ID; date if known; status (`PROPOSED`, `CONFIRMED`, `REJECTED`, `SUPERSEDED`); context; exact decision; alternatives; rationale/evidence; affected agents/files; approver; supersedes/superseded-by.

Automatic routine installation of compatible archives is a confirmed policy. Do not treat this as permission to execute archive scripts, elevate privileges, expose secrets, or destroy existing files. Never silently change user-confirmed decisions.
