# DISCOVERY_SKILL

Before acting:
1. Read installer memory and shared registry/state.
2. Identify project root and runtime evidence.
3. Inventory archives and installed agents.
4. Identify missing runtime documentation, conflicting identities, unsupported dependencies and potential destructive changes.
5. Ask the user only when the project root or a consequential conflict cannot be resolved safely. Routine valid installs proceed automatically.
6. Classify unknowns as blocking or non-blocking and record them.

Never claim a runtime, permission, installation path or tool exists without evidence. When runtime is unknown, preserve the archive and report the blocker rather than guessing.
