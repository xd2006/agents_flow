# DOCUMENTATION_SKILL

At the end of each task/batch, write a Markdown report under `Agent_Memory/AF-Intaller/tasks/`.

Required fields: task ID; actual date/time if available; agent; project root; status; discovered archives; runtime evidence; documentation consulted; work performed; installed/created/changed files; validation checks and results; decisions; conflicts; blockers; next steps.

Use one result per archive: `INSTALLED`, `READY`, `BLOCKED`, `SKIPPED_DUPLICATE`, or `FAILED`. Include relative paths. Never invent timestamps, paths, tests, or successful writes. Preserve source ZIPs by default. At end, update `WORK_LOG.md` and concise durable lessons in `MEMORY.md`.
