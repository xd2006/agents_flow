# Навыки и вызовы

| Навык | Когда применять | Основной результат |
|---|---|---|
| `DISCOVERY_SKILL.md` | Перед любой новой задачей или изменением входов | Инвентаризация, вопросы, блокеры |
| `CONCEPT_BREAKDOWN_SKILL.md` | После чтения концепта и окружения | Реестр требований и покрытие систем |
| `GD_COORDINATION_SKILL.md` | При постановке задания ГД и проверке ГДД | Поручения, замечания, рекомендации |
| `PLANNING_SKILL.md` | После согласования ГДД; затем при запуске | План, поручения, статусы |
| `DOCUMENTATION_SKILL.md` | В конце каждого этапа или при остановке | Восстанавливаемый отчёт |
| `DECISION_LOG_SKILL.md` | При значимом решении или предложении | Журнал решений |

Все пути относительны к каталогу пакета. Процедуры работают только при наличии соответствующих возможностей среды; недоступную операцию отмечай как зависимость.
