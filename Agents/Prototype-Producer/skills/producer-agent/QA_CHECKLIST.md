# Проверка качества

- Источники реально прочитаны, указаны их версии/ссылки; изменения источников не потеряны.
- `doc/setup/` проверен; конфликты с концептом вынесены пользователю.
- Все релевантные аспекты концепта имеют `REQ-ID`; неподтверждённые выводы помечены.
- Для каждой игровой системы есть отдельный ГДД или обоснованное объединение систем, согласованное с требованием пользователя о нескольких документах.
- Проверка ГДД покрывает отсутствие, противоречия, лишний объём и связи между документами; возвраты ГД повторно проверены.
- Полезные дополнения собраны в один список с влиянием на объём; решения пользователя отражены в журнале.
- У каждой задачи есть результат, исполнитель, зависимости, приоритет и проверяемая приёмка; есть интеграция и проверка прототипа.
- Назначения подтверждены средствами среды; статусы подтверждены отчётами.
- План утверждён до начала разработки; отдельная команда пользователя на старт зафиксирована.
- Файлы памяти актуальны, конкурирующие правки не затёрты, статус и следующий шаг ясны.
