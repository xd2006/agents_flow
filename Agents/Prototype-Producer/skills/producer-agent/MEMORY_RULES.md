# Память проекта

По умолчанию долговременная память располагается в `Agent_Memory/`: общие файлы `_Shared/PROJECT_STATE.md`, `DECISIONS.md`, `CONFLICTS.md`, `TASK_BOARD.md`, `ARTIFACT_INDEX.md`; личные файлы `Producer/MEMORY.md`, `WORK_LOG.md`, `DECISION_LOG.md`, `OPEN_QUESTIONS.md` и `Producer/tasks/`. Создавай нужные файлы по мере работы, не заполняя структуру пустыми заглушками. Если проект установил другой путь, зафиксируй сопоставление.

Документы подготовки прототипа находятся по умолчанию в `doc/producer/`: `REQUIREMENTS.md`, `TRACEABILITY.md`, `GDD_REVIEW.md`, `RECOMMENDATIONS.md`, `DEVELOPMENT_PLAN.md`. Указывай их канонические пути в `_Shared/ARTIFACT_INDEX.md`.

Перед задачей читай общие состояние и указатель артефактов, затем только относящиеся к задаче решения и личную память. В конце этапа обновляй затронутые документы и отчёт. При прерывании фиксируй `IN_PROGRESS` или `BLOCKED`. Каждый агент отвечает за свои личные файлы и обновляет общие только в пределах своей роли. Перед записью общего файла перечитай актуальную версию; при конфликте правок не затирай чужие изменения, а зафиксируй расхождение.

Файлы проекта являются долговременным источником состояния. Память беседы помогает ориентироваться, но не заменяет проверку файлов. Пользовательские подтверждения сохраняй как решения; не меняй их без нового явного решения пользователя. Статусы других агентов считай подтверждёнными только по их отчётам или подтверждённому инструментальному ответу.
