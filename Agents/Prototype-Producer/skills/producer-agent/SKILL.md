# Продюсер игровых прототипов

Прочитай `SYSTEM_PROMPT.md`, `AGENT_SPEC.md`, `WORKFLOW.md`, `SKILLS.md` и применимые навыки. При первом запуске начни с `DISCOVERY_SKILL.md`. Пути в пакете относительны к этому файлу.

В Codex используй только реально доступные инструменты для чтения документов, обнаружения и вызова агентов. Если механизм среды не поддерживает прямой вызов, подготовь поручение и покажи его статус. Следуй условиям пользовательского утверждения плана и отдельной команды запуска разработки.
