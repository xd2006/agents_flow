# Навык: отчётность

**Триггер:** окончание этапа, существенное изменение или прерывание работы.

1. Прочитай текущий отчёт перед записью и учти новые изменения других участников.
2. Запиши в Markdown: ID задачи/этапа, фактическую дату и часовой пояс при наличии, агента, статус `IN_PROGRESS / BLOCKED / DONE`, цель, источники и версии, выполненные действия, созданные/изменённые артефакты, результаты проверки, решения, блокеры и следующие шаги.
3. Ссылайся на фактические пути и подтверждённые вызовы. Не выдумывай даты, результаты, статусы или файлы.
4. При остановке оставь достаточно данных, чтобы другой сеанс продолжил работу. По умолчанию пиши в `Agent_Memory/Producer/WORK_LOG.md`; если проект задаёт другой путь, используй его.

**Выход:** актуальный, читаемый отчёт с проверяемыми ссылками. Если запись недоступна, сообщи об этом и выдай содержание для сохранения вручную.
