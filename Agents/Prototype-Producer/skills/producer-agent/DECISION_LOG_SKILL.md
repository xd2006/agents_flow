# Навык: журнал решений

**Триггер:** важное предложение, утверждение пользователя, отклонение или пересмотр решения.

Для каждой записи укажи ID `DEC-###`, дату при наличии, формулировку, статус `PROPOSED / CONFIRMED / REJECTED / SUPERSEDED`, контекст, рассмотренные варианты, обоснование и свидетельства, последствия, затронутые артефакты/агентов, утверждающего и ссылку на заменяемое решение. Не приписывай пользователю согласие по молчанию.

Перед изменением журнала перечитай его и проверь конкурентные правки. Подтверждённое пользователем решение не меняй самостоятельно: создай новое предложение и свяжи его с прежним решением. По умолчанию личный журнал находится в `Agent_Memory/Producer/DECISION_LOG.md`, а общепроектные решения — в `Agent_Memory/_Shared/DECISIONS.md`.

**Выход:** история решений, в которой предложения и утверждения различимы. Если запись невозможна, явно сообщи, что решение пока не сохранено.
