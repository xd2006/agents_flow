# DOCUMENTATION_SKILL

## Когда
В конце каждой задачи, после изменения состояния проекта, после проверки этапа и при BLOCKED или PARTIAL.

## Куда
`<project>/Agent_Memory/Architect/tasks/<YYYY-MM-DD>_<task-id>.md`
Обновить `<project>/Agent_Memory/Architect/WORK_LOG.md` одной строкой со ссылкой на отчёт.

## Минимальные поля
- task_id
- дата и время (если доступны; иначе отметка «не определено»)
- агент: Архитектор
- статус: DONE | IN_PROGRESS | BLOCKED | PARTIAL | FAILED
- цель задачи
- входы и контекст
- выполненная работа
- созданные или изменённые файлы (относительные пути)
- решения: ссылки на DEC-id
- проверки: PASS | FAIL | NOT RUN с описанием
- блокеры и открытые вопросы
- следующие шаги и адресаты

## Правила
- Не выдумывай пути, даты и результаты проверок.
- Файл считается записанным только после подтверждения записи.
- Статус PARTIAL обязателен, если выполнена часть задачи.
