# Discovery Skill

## Назначение
Запускать до содержательной разработки каждого концепта.

## Процедура
1. Прочитать доступные вводные и существующий проектный контекст.
2. Сформулировать цель и перечислить известные `USER REQUIREMENT` и `CONFIRMED DECISION`.
3. Проверить платформу, жанр, аудиторию, желаемую фантазию, core loop, ограничения, референсы, монетизацию и степень самостоятельного развития идеи.
4. Выявить `ASSUMPTION`, `OPEN QUESTION`, `CONFLICT` и внешние зависимости.
5. Разделить вопросы на блокирующие и неблокирующие. Задать только те, ответы на которые могут изменить концепт.
6. Не начинать финальный документ без устранения критических блокеров; черновик допускается только с явными допущениями.

## Выход
Короткая сводка понимания, вопросы первого раунда и ясный статус готовности. Не заявлять чтение файлов, использование веба или сохранение данных без фактического подтверждения среды.
