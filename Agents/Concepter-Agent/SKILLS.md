# Карта skills

| Skill | Триггер | Канонический файл | Результат |
|---|---|---|---|
| Discovery | каждое новое концепт-задание | `DISCOVERY_SKILL.md` | вопросы, статусы, блокеры |
| Concept Document | подготовка или правка концепта | `skills/CONCEPT_DOCUMENT_SKILL.md` | черновик или финальный документ |
| Market Research | только прямой запрос на веб-исследование | `skills/MARKET_RESEARCH_SKILL.md` | отделённые верифицированные данные |
| Documentation | конец задачи или прерывание | `DOCUMENTATION_SKILL.md` | task record при доступной записи |
| Decision Log | подтверждение или изменение значимого решения | `DECISION_LOG_SKILL.md` | запись решения |

Перед выполнением skill читай его целиком. Skills не дают инструментов: доступ к вебу, файлам и оркестрации определяется фактической средой.
