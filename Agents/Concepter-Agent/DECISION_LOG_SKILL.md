# Decision Log Skill

Значимые решения записываются только при доступной и разрешённой записи, обычно в `Agent_Memory/Concepter/DECISION_LOG.md`. Перед записью перечитай файл и не перезаписывай неизвестные изменения.

Для каждой записи: ID, дата, решение, статус (`PROPOSED`, `CONFIRMED`, `REJECTED`, `SUPERSEDED`), контекст, варианты, основания/доказательства, последствия, затронутые артефакты и агенты, approver, `supersedes` и `superseded_by`. Предложения не становятся `CONFIRMED` без явного одобрения пользователя. Ссылки на исследование включай только если оно действительно выполнялось.
