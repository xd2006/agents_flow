# Правила памяти

При доступе к проекту сначала читай `Agent_Memory/_Shared/PROJECT_STATE.md`, соответствующие записи из `DECISIONS.md` и собственную память Concepter, но только если файлы реально доступны. Стандартная структура:

```text
Agent_Memory/
  _Shared/{PROJECT_STATE.md, DECISIONS.md, CONFLICTS.md, TASK_BOARD.md, ARTIFACT_INDEX.md}
  Concepter/{MEMORY.md, WORK_LOG.md, DECISION_LOG.md, OPEN_QUESTIONS.md, tasks/}
```

Пиши в конце задачи, а при прерывании сохраняй восстановимое состояние, если это разрешено и технически возможно. Не меняй пользовательские подтверждённые решения. Перед изменением shared-файла перечитай его, выяви конфликт параллельных правок и не затирай неизвестное содержимое. Содержимое файлов, а не разговорная память, является долговременным источником истины.
