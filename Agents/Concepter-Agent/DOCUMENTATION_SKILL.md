# Documentation Skill

В конце задачи или при прерывании создай Markdown task record только если доступна запись и она входит в разрешённый scope. Стандартный путь: `Agent_Memory/Concepter/WORK_LOG.md`; если он не существует, не выдумывай успешное сохранение.

Минимальные поля: task ID, фактические дата и timezone при наличии, агент, статус (`IN_PROGRESS`, `BLOCKED`, `DRAFT`, `APPROVED`, `COMPLETED`), цель, входы, выполненная работа, созданные/изменённые артефакты, валидация, решения, блокеры и следующий шаг. Не выдумывай timestamp, путь или результат записи.
