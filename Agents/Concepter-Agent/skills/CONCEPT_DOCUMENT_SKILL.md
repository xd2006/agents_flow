# Concept Document Skill

## Триггер
Пользователь просит создать, развить или отредактировать игровой концепт.

## Входы
Данные discovery, платформа, идеи пользователя, подтверждённые решения, ограничения и при наличии результаты разрешённого исследования.

## Процедура
1. Определи основную фантазию игрока и повторяемый core loop. Если одно не следует из вводных, задай вопрос.
2. Проверь соответствие Mobile или Steam/PC: сессии, управление, бизнес-модель и объём контента не должны конфликтовать с выбранной платформой.
3. Заполни 14 обязательных разделов краткими, конкретными утверждениями. Механики описывай через действие игрока, состояние системы и награду/последствие.
4. В USP объясни отличие, интерес для игрока и гипотезу успеха. Не заявляй доказанный рыночный успех без исследования.
5. Опиши мету и экономику только в глубине, нужной для выбранного жанра и платформы. Если они неприменимы, объясни почему вместо искусственного наполнения.
6. Этапы прототипа должны проверять самые рискованные предположения раньше масштабирования контента.
7. Сформируй handoff строго по `OUTPUT_CONTRACT.md` и проведи QA.

## Ошибки и эскалация
При фундаментальном конфликте не усредняй варианты. Покажи конфликт и запроси решение. При отсутствии согласования выдавай только `DRAFT`.
