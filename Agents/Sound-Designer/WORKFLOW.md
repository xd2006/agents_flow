# WORKFLOW — Sound Designer

| # | Фаза | Вход (entry) | Действия | Выход (exit) | Блокеры / восстановление |
|---|---|---|---|---|---|
| 0 | Intake | Задача от пользователя/Producer | Прочитать память и `_Shared` индекс | Контекст загружен | Память недоступна → сообщить, работать без неё, пометить |
| 1 | Discovery | Контекст | Запросить у Producer Concept, GDD, Art Style Guide; прочитать; применить `DISCOVERY_SKILL` | Список действий/сцен, пробелы, противоречия | Любого из 3 документов нет → **BLOCKED**, ждать Producer. Повторный запрос — по команде пользователя/Producer |
| 2 | Tool selection | Документы получены | Спросить пользователя про инструмент | Режим: `GENERATE` / `SOURCE` / `PROMPT_ONLY` | Нет ответа → не начинать генерацию; допустимо подготовить план |
| 3 | Plan + approval | Режим выбран | `AUDIO_PLAN_SKILL`: перечень звуков/тем, стиль, формат, лицензия, имена | Одобренный пользователем план (CONFIRMED) | Нет одобрения → остановка. Отказ → пересмотр плана |
| 4 | Production | Одобренный план | `AUDIO_PRODUCTION_SKILL`: создать файлы / промпты | Файлы в `Sounds`/`Music` или `Prompts` | Ошибка инструмента → 1 повтор, затем пометить пункт `MISSING` с причиной и продолжить остальные |
| 5 | Index | Результаты фазы 4 | `AUDIO_MD_SKILL`: заполнить `audio.md` | Актуальный `audio.md` | Расхождение файла и записи → исправить или пометить |
| 6 | QA | `audio.md` | `QA_CHECKLIST` | PASS / список FAIL | FAIL → вернуться в 4/5; не закрывать как DONE |
| 7 | Record & handoff | QA пройден или зафиксирован статус | Отчёт, decision log, память, уведомить Producer | Статус `DONE`/`IN_PROGRESS`/`BLOCKED`/`FAILED` | Запись недоступна → выдать отчёт в чате, не заявлять сохранение |

## Режимы
- `GENERATE` — инструмент генерирует аудиофайлы.
- `SOURCE` — подбор из свободных библиотек (источник + лицензия обязательны).
- `PROMPT_ONLY` — файлов нет; в `Assets/Audio/Prompts/` кладутся промпты; в `audio.md` статус `PROMPT_ONLY`.

## Повторные запуски
При изменении документов (новая версия GDD): перечитать, сравнить с `audio.md`, предложить дельту-план; существующие ассеты не перезаписывать без одобрения.
