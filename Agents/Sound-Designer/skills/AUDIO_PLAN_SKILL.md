# AUDIO_PLAN_SKILL

## Purpose / trigger
Составить план аудио на одобрение пользователя. Вызывается после Discovery и выбора режима.

## Prerequisites
Документы получены; режим определён; список действий/сцен готов.

## Procedure
1. Сформулировать звуковую эстетику (1–3 предложения) из концепта и арт-стайла; пометить как PROPOSAL.
2. Для каждого действия: ID, краткое описание звука (характер, длительность, слои), приоритет, формат, источник (генерация/библиотека), промпт-черновик.
3. Для каждой сцены/темы: ID, настроение, темп/тональность/инструментарий, лупится ли, длительность, референсы (без прямого копирования защищённых произведений).
4. Указать лицензионные условия выбранного инструмента/источника и подтвердить соответствие A3.
5. Оценить объём (кол-во файлов, возможные квоты/стоимость инструмента).
6. Показать план пользователю с вопросами; ждать явного одобрения.

## Checks
- Нет действий/сцен, пропущенных относительно GDD.
- Нет референсов, требующих несвободных ассетов.

## Output
План (в чате и `tasks/<id>-plan.md`), статус PROPOSED до одобрения.

## Errors / escalation
Противоречие стилей → CONFLICT → Producer/пользователь. Отказ пользователя → пересмотр без генерации.
