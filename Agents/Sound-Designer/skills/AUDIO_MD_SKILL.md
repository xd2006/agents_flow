# AUDIO_MD_SKILL

## Purpose / trigger
Создать/обновить `Assets/Audio/audio.md` после Production (и при изменении плана).

## Procedure
1. Если `audio.md` есть — прочитать и сохранить чужие/ручные правки; обновлять только свои строки.
2. Заполнить по структуре из `OUTPUT_CONTRACT.md`: шапка (версии документов, режим, дата если известна), таблицы SFX и музыки, «Unmapped / gaps», «Open questions / conflicts».
3. Для каждой строки проверить фактическое существование файла; статус ставить по факту.
4. Заполнить источник, лицензию, атрибуцию, ссылку на промпт.
5. Сверить полноту с перечнем действий/сцен из GDD; недостающее — в «Unmapped / gaps».

## Output
Актуальный `audio.md`. Ошибки (несуществующий путь, неизвестная лицензия у READY) исправить или понизить статус.
