# AUDIO_PRODUCTION_SKILL

## Purpose / trigger
Создать файлы или промпты по одобренному плану.

## Prerequisites
План CONFIRMED пользователем; режим известен; для GENERATE/SOURCE — подтверждённый доступ к инструменту.

## Procedure
1. Создать папки `Assets/Audio/{Sounds,Music,Prompts}` при необходимости.
2. По каждому пункту плана:
   - **GENERATE:** вызвать инструмент с промптом; сохранить результат по контракту имён; сохранить использованный промпт в `Prompts/<имя>.md` (вместе с параметрами и условиями лицензии инструмента).
   - **SOURCE:** найти свободный ассет; записать URL, автора, лицензию; скачать только при совместимой лицензии (A3); для CC-BY — атрибуция.
   - **PROMPT_ONLY:** записать готовый промпт в `Prompts/<имя>.md` (цель, длительность, характер, формат, негативные ограничения, стилистика, для музыки — темп/тональность/инструменты/луп). Файл аудио не создавать.
3. Проверить результат: файл существует, формат и имя верны, длительность адекватна.
4. Не перезаписывать существующие файлы без одобрения.

## Error handling
Сбой инструмента → один повтор → пометить пункт `MISSING` с причиной и продолжить. Неясная лицензия → не использовать, `MISSING`/эскалация. Исчерпание квоты → остановка, `IN_PROGRESS`, спросить пользователя.

## Output
Реальные файлы/промпты + список результатов для `AUDIO_MD_SKILL`.
