# DISCOVERY_SKILL — Sound Designer

## Purpose and trigger
Выполняется в начале каждой задачи, до любой генерации.

## Procedure
1. Прочитать задачу и свою память (`MEMORY_RULES.md`). Переформулировать цель в 1–2 предложения.
2. **Запросить у Producer напрямую**: Concept Document, GDD, Art Style Guide (с версиями/путями). Не запрашивать то, что уже есть и актуально в памяти — но сверить версию.
3. Если любой документ отсутствует/пуст/нечитаем → статус `BLOCKED`, сообщить Producer и пользователю, какого документа нет. Дальше не идти.
4. Прочитать документы фактически. Извлечь:
   - **Игровые действия** (GDD): каждое действие игрока/врага/системы/UI, которое должно звучать; присвоить идентификатор `<имя_действия>`.
   - **Сцены/состояния** (GDD, концепт): меню, уровни, бой, победа/поражение, титры и т. п.
   - **Звуковые ориентиры**: настроение, жанр, референсы, эпоха/сеттинг (концепт); визуальный тон, палитра, стилизация (арт-стайл) → звуковая эстетика (реалистично/стилизовано/ретро и т. п.).
5. Найти пробелы, противоречия, зависимости (например: действие без идентификатора; концепт «мрачно», арт-стайл «яркий мультяшный»). Классифицировать: USER REQUIREMENT / ASSUMPTION / OPEN QUESTION / CONFLICT.
6. Заранее спросить домен-специфичное, если не определено: движок и требуемые форматы; ограничения по размеру/длительности; лупы для музыки; платформа; нужны ли варианты звуков.
7. Определить блокеры.

## Что блокирует
- Отсутствие любого из 3 документов.
- Конфликт документов, из-за которого нельзя определить стиль (эскалировать Producer/пользователю).
(Отсутствие идентификаторов действий/сцен в GDD **не блокирует**: агент придумывает их по смыслу, snake_case, помечает `assigned` и сообщает Producer.)

## Что не блокирует
- Нет инструмента генерации (→ `PROMPT_ONLY`).
- Неизвестен формат (→ дефолт WAV/OGG, ASSUMPTION).

## Output
Краткое резюме: найденные действия и сцены (счётчики), звуковая эстетика, список вопросов/конфликтов с метками, блокеры, предложенные дефолты. Не начинать необратимую работу, пока есть критические блокеры.
