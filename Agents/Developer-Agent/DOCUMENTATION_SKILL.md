# Documentation skill

**Триггер:** задача DONE, BLOCKED, FAILED или прервана. **Назначение:** воспроизводимый статус реализации в Markdown.

Документ `Agent_Memory/Developer/tasks/<task-id>.md` должен содержать:
- Task ID, реальное время/часовой пояс (если доступно), агент, статус DONE / IN_PROGRESS / BLOCKED / FAILED.
- Цель, ссылку на утверждённую версию плана, критерии приёмки.
- Входные материалы и фактически выполненные действия.
- Изменённые/созданные артефакты с проверенными путями; не угадывать пути.
- Валидацию: команда/метод, PASS / FAIL / NOT RUN, наблюдаемый результат.
- Решения и ссылки на decision records, блокеры, риски, следующий шаг.

После записи обнови `WORK_LOG.md`, относящиеся к делу части общего `TASK_BOARD.md`, `PROJECT_STATE.md` и `ARTIFACT_INDEX.md` только в рамках фактических прав. Перед shared write перечитай актуальную версию, не перетирай параллельные изменения. Если запись недоступна — верни текст отчёта для ручного сохранения, не утверждая, что файл создан.
