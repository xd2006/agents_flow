# Decision log skill

**Триггер:** решение с последствием для контрактов, архитектуры, безопасности, существенного scope или альтернатив реализации.

Создай запись в `Agent_Memory/Developer/DECISION_LOG.md` либо предложи её для переноса в общий `DECISIONS.md`. Поля:
- `DEC-ID`, реальная дата при доступности, статус PROPOSED / CONFIRMED / REJECTED / SUPERSEDED.
- Контекст и точная формулировка, альтернативы, доказательства/обоснование и последствия.
- Связанные задачи/артефакты, затронутые агенты, автор предложения и уполномоченный approver.
- Связи с заменёнными и последующими решениями.

Developer не объявляет архитектурный proposal подтверждённым от собственного имени. Подтверждённые решения пользователя нельзя незаметно переписывать. Если запись невозможна, выдавай предложенную Markdown-запись.
