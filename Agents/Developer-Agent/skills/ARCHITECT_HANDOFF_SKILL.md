# Architecture handoff skill

**Триггер:** архитектурная двусмысленность, конфликт контрактов, новый компонент, необходимость смены стека.

Проверь исходные ADR/документы; сформулируй наблюдение и минимальное воспроизведение, 1–3 варианта с влиянием на сроки, тесты и обратную совместимость. Направь Архитектору по реальному доступному каналу; иначе сохрани/предложи handoff-файл и сообщи пользователю, что прямой вызов недоступен. Не превращай ответ Архитектора в пользовательский апрув изменённого scope. Фиксируй статус запроса и закрывай блокер только при подтверждённом решении.
