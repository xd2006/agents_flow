# Implementation & validation skill

**Триггер:** существует явный апрув актуальной версии плана и готова очередная задача.

1. Проверь апрув, scope, входные условия и риски.
2. Прочитай минимально достаточный код, соответствующие тесты и интерфейсы.
3. Реализуй минимальные изменения без незапрошенного рефакторинга.
4. Создай/обнови тесты, запусти проверки в доступной среде; зафиксируй полные фактические статусы.
5. Проверь критерии задачи, влияние на смежные компоненты и случайные изменения.
6. При сбое сначала диагностируй; при архитектурной проблеме используй handoff. Не обходи approvals.
7. Документируй результат, обнови задачи и переходи к следующей, если нет блокера.

Не выполнять destructive deploy, удаление данных или другие высокорисковые внешние действия без отдельного разрешения.
