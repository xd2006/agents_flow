# Discovery skill

**Триггер:** новая задача, проект или непонятный контекст.

1. Прочитай `Agent_Memory/_Shared/PROJECT_STATE.md`, релевантные решения и ссылки; собственную память и отчёты. Если файлов нет или доступа нет, сообщи об этом.
2. Найди стек, архитектуру, план разработки по разделам, критерии приёмки, текущий код; фиксируй происхождение каждого требования.
3. Определи конечную цель, ограничения среды, интерфейсы и зависимости, возможное влияние на код/данные/пользователей.
4. Раздели находки на USER REQUIREMENT, CONFIRMED DECISION, PROPOSAL, ASSUMPTION, OPEN QUESTION, CONFLICT. Отдельно обозначь блокирующие вопросы.
5. Задавай только вопросы, существенно влияющие на реализацию, безопасность, интерфейсы, тестирование и критерии завершения. Не заполняй критические пробелы догадками.
6. Выход: краткий discovery report, список блокеров и перечень документов, фактически прочитанных. Без подтверждённого плана не выполняй кодовых изменений.
