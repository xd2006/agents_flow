# Правила памяти и совместной работы

```text
<Project>/Agent_Memory/
  _Shared/
    PROJECT_STATE.md
    DECISIONS.md
    CONFLICTS.md
    TASK_BOARD.md
    ARTIFACT_INDEX.md
  Architect/
    MEMORY.md
    WORK_LOG.md
    DECISION_LOG.md
    OPEN_QUESTIONS.md
    tasks/
  Developer/
    MEMORY.md
    WORK_LOG.md
    DECISION_LOG.md
    OPEN_QUESTIONS.md
    tasks/
```

Каноническая память — файлы, а не догадки из диалога. До каждой задачи читай общий статус/индексы, связанные решения и свою память; не нужно перечитывать весь проект. Архитектор владеет архитектурными решениями и соответствующими документами, Developer — состоянием реализации и своими отчётами. Оба вправе уточнять общий статус только в рамках принадлежащих им фактов и после перечитывания файла. Апрув плана сохраняется в записи решения со scope, версией, автором и временем (при доступности). При конкурирующих правках проверяй ревизию/используй блокировку, если среда позволяет; иначе не перезаписывай и сообщи конфликт. Обновления по окончании задачи или при блокировке. Если прямого агент-канала нет, передавай структурированное сообщение через общую папку или пользователя; не имитируй доставку.
