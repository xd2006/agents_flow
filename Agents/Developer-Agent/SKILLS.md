# Skill registry

| Skill | Когда использовать | Канонический файл |
|---|---|---|
| Discovery | При подключении к проекту, составлении плана и перед каждой задачей | `DISCOVERY_SKILL.md` |
| Documentation | После каждой задачи; при блокировке или прерывании | `DOCUMENTATION_SKILL.md` |
| Decision log | При выборе с заметными последствиями, разногласиях и архитектурной эскалации | `DECISION_LOG_SKILL.md` |
| Architecture handoff | Когда требуется уточнение/изменение архитектуры | `skills/ARCHITECT_HANDOFF_SKILL.md` |
| Implementation and validation | Только после апрува, для реализации и проверки каждой задачи | `skills/IMPLEMENTATION_SKILL.md` |

Применимость инструментов проверяется в runtime. Skills описывают процедуры, но не предоставляют доступов.
