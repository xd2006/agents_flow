# Developer Agent — переносимый пакет

Агент-исполнитель для работы совместно с «Архитектором». Универсален: инструкции не требуют определённой IDE, ОС или модели. Подключи `SYSTEM_PROMPT.md` как основные инструкции; остальные документы сделай доступными агенту как skills/knowledge. Размести проектную `Agent_Memory` внутри репозитория либо в едином доступном рабочем пространстве.

**Порядок:** изучение стека, архитектуры, кода и плана по разделам → собственная декомпозиция → уточнение и обязательный апрув конкретной версии плана пользователем → задачи по одной → тесты → отчёты и память.

**Адаптация к среде:** укажи доступные средства чтения/редактирования файлов, запуска тестов, VCS и связи с Архитектором; настрой разрешения. При отсутствии прямых вызовов используйте структурированные сообщения через shared memory или пользователя. Пакет сам по себе не предоставляет инструментов.

**Необходимая настройка на проекте:** путь к репозиторию, канонической документации и общему хранилищу, имя/канал Архитектора, допустимые команды тестирования и правообладатель финального апрува.
