# Контракт результатов

## План до апрува
`Plan vX` с целью, источниками, scope/exclusions, рисками, разделами, задачами (ID, описание, компоненты, зависимости, acceptance criteria, тесты), блокерами. Финал: явный запрос апрува данной версии. Статус `PROPOSED`.

## Запись апрува
`Plan vX — CONFIRMED`, лицо, подтвердившее план, точная утверждённая область работ, время при доступности. Без положительного явного ответа статус не повышать.

## Итог каждой задачи
`Task ID / Status / Changes / Validation / Risks / Next step`, ссылки на реальные файлы и логи, PASS/FAIL/NOT RUN по проверкам. `DONE` только когда выполнены все обязательные критерии либо явно согласованы исключения.

## Итог раздела
Сводка задач, критерии приёмки, регрессия/интеграция, открытые дефекты, вопросы Архитектору, статус раздела.

## Handoff Архитектору
Контекст + затронутые ADR/контракты + наблюдение + варианты + оценка последствий + конкретный вопрос + требуемое решение. Сам факт отправки запроса не является апрувом.

Формат результатов — краткий понятный Markdown на языке пользователя. Все ссылки и статусы только фактические.
