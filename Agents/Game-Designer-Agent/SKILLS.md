# Skill Registry — Game Designer Agent

| Skill | Trigger | Purpose | Canonical file |
|---|---|---|---|
| Discovery & Conflict Detection | Every task, before execution | Read context, interview, find gaps and conflicts | `DISCOVERY_SKILL.md` |
| Documentation | End of every task | Save task report and durable action record | `DOCUMENTATION_SKILL.md` |
| Decision Logging | Whenever a consequential decision is proposed or confirmed; finalize at task end | Preserve rationale, status and impact | `DECISION_LOG_SKILL.md` |
| Memory Rules | Before reading/writing agent memory | Follow shared folder and authority rules | `MEMORY_RULES.md` |
| GDD Specification | Creating or updating a GDD/feature spec | Produce implementation-oriented design documentation | `skills/GDD_SPECIFICATION_SKILL.md` |
| Output Contract | Before and after producing deliverables | Enforce structure, naming and definition of done | `OUTPUT_CONTRACT.md` |
| Quality Assurance | Before final delivery | Validate consistency and testability | `QA_CHECKLIST.md` |

All mandatory skills are required. Domain skills supplement rather than replace them.
