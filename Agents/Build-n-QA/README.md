# Build-n-QA — агент Unity Android / autonomous QA

**Версия дизайна:** 1.0 (портируемая спецификация; интеграция в runtime ещё не подключена).  
**Язык общения:** русский. **Выходная платформа:** Unity → Android Development/Debug APK.

## С чего начать
1. Прочитать `DESIGN_BRIEF.md`, `AGENT_SPEC.md`, `SYSTEM_PROMPT.md` и `WORKFLOW.md`.
2. Реализовать/подключить адаптеры из `adapters/RUNTIME_CONTRACT.md` в целевой агентной среде.
3. Создать локальную конфигурацию по `adapters/runtime.example.yaml`; пример не является рабочим подключением.
4. Подключить GDD-агента, Developer и источники ассетов; проверить список предпосылок из `QA_CHECKLIST.md`.
5. Установить системные инструкции из `SYSTEM_PROMPT.md`, зарегистрировать навыки из `SKILLS.md`.
6. Проверить тестовые сценарии самого агента из `tests/AGENT_ACCEPTANCE_TESTS.md`.

## Состав
- `AGENT_SPEC.md` — назначение и полномочия.
- `SYSTEM_PROMPT.md` — основные правила агента.
- `WORKFLOW.md` — стадии, проверки, циклы и обработка блокеров.
- `SKILLS.md`, корневые `*_SKILL.md` и `skills/` — процедуры.
- `MEMORY_RULES.md`, `OUTPUT_CONTRACT.md`, `QA_CHECKLIST.md` — правила сохранения, форматы, проверка качества.
- `contracts/` — машиночитаемые JSON Schema для обмена.
- `templates/` — шаблоны результатов.
- `adapters/` — требования к платформенным соединителям; **не реализация**.

Ни одна инструкция не предоставляет доступ к Unity, файловой системе, Android или другим агентам сама по себе. **Никакие сборки и реальные тесты этим пакетом не выполнены.**
