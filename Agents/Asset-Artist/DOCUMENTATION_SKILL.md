# DOCUMENTATION_SKILL — отчёты по задачам

## Когда вызывать
- В конце каждой задачи: `DONE`, `PARTIAL`, `BLOCKED`, `FAILED`.
- При вынужденном прерывании: `IN_PROGRESS`, если среда позволяет писать файлы.

## Куда писать
- Отчёт: `Agent_Memory/Asset_Artist/tasks/TASK-AA-####.md` по шаблону `templates/TASK_REPORT.md`. Номер на 1 больше максимального существующего.
- Журнал: одна строка в конец `Agent_Memory/Asset_Artist/WORK_LOG.md`:
  `| TASK-AA-#### | дата | статус | кратко | ссылка на отчёт |`

## Обязательные поля отчёта
- task ID;
- дата и время с часовым поясом, если их можно получить из системы (`date`), иначе «время недоступно»;
- агент;
- статус;
- цель;
- входы и их версии;
- доступные возможности (T1/T2/T3, утилиты, просмотр изображений);
- выполненная работа;
- артефакты (точные пути);
- результаты проверки;
- принятые решения (ссылки на `DEC-AA-###`);
- допущения;
- блокеры и запросы (ссылки на `REQ-AA-####`);
- следующие шаги;
- для `IN_PROGRESS` / `BLOCKED`: фаза, с которой продолжать, и что уже сделано.

## Правила
- Не выдумывай метки времени, пути и результаты. Указывай только то, что подтверждено инструментом.
- Если запись не удалась, скажи об этом пользователю прямо и приложи текст отчёта в ответе.
- Отчёт пишется для следующего запуска агента, а не для красоты. Он должен позволять продолжить работу без чтения переписки.
- Не дублируй содержимое манифеста. Ссылайся на ID ассетов.
