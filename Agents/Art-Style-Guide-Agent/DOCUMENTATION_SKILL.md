# Documentation Skill

В конце задачи, а при блокировке — до остановки, создать или обновить Markdown-отчёт в разрешённой памяти агента. Перед обновлением перечитать файл и не стирать чужие изменения.

Минимальные поля: идентификатор задачи, дата и часовой пояс если доступны, агент, статус, цель, входы, выполненная работа, созданные или изменённые артефакты, проверки, решения, блокеры и следующий шаг.

Допустимые статусы: DONE, PARTIAL, BLOCKED, IN_PROGRESS. Не придумывай время, пути или результаты записи.
