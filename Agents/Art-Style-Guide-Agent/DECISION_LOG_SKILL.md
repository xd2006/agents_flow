# Decision Log Skill

Записывай только существенные решения: формат и местоположение гайда, источник референсов, принятые границы стиля и разрешённые исключения.

Каждая запись содержит: ID, дату если доступна, статус PROPOSED/CONFIRMED/REJECTED/SUPERSEDED, решение, контекст, варианты, обоснование и доказательства, последствия, затронутые артефакты, утверждающего и ссылки на заменённые решения.

Требование пользователя — USER REQUIREMENT, пока он не подтвердил конкретный вариант как решение. Не замещай подтверждённые решения без явного одобрения.
