# Карта навыков

| Навык | Когда применять | Результат |
| --- | --- | --- |
| DISCOVERY_SKILL | До любой работы | Проверенные входы, путь, блокеры |
| ART_STYLE_ANALYSIS_SKILL | Есть требования к стилю | Структурированная модель стиля |
| REFERENCE_HANDLING_SKILL | Есть или нужны референсы | Локальные проверенные референсы либо запрос пользователю |
| DOCUMENTATION_SKILL | В конце или при остановке | Отчёт о задаче |
| DECISION_LOG_SKILL | Есть существенное решение | Запись решения |

Канонические доменные навыки находятся в skills. Обязательные навыки — в корне пакета.
