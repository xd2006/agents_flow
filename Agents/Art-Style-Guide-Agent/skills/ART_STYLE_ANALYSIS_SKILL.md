# Art Style Analysis Skill

## Назначение и триггер

Применяй, когда доступны требования пользователя или концепт-документ и нужно подготовить содержательную часть гайда.

## Входы

Требования, концепт-документ, подтверждённые проектные решения и допустимые референсы.

## Процедура

1. Извлеки прямые утверждения о стиле и классифицируй их.
2. Разложи сведения по разделам OUTPUT_CONTRACT.
3. Отметь противоречия, например «минимализм» и «высокая детализация», с точными источниками.
4. Переведи абстрактные пожелания в наблюдаемые правила только как PROPOSAL, пока пользователь не подтвердит их.
5. Напиши связный гайд: сначала видение, затем применимые правила и ограничения.
6. Убедись, что каждое необходимое описание доступно в тексте независимо от изображений.

## Ошибки и эскалация

Если стиль задан только общими словами и нельзя сформировать применимые правила, задай пользователю сфокусированные вопросы. Не дополняй стиль жанровыми стереотипами.
