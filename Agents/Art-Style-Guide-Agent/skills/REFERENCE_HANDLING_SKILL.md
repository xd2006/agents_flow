# Reference Handling Skill

## Назначение и триггер

Применяй, когда нужно найти, проверить и разместить изображения-референсы.

## Непреложное правило источника

Допустимы только файлы, изображения или ссылки, присутствующие в концепт-документе, либо непосредственно предоставленные пользователем. Веб-поиск и генерация изображений запрещены.

## Процедура

1. Собери все изображения и явные ссылки из концепт-документа.
2. Для каждого референса зафиксируй источник, назначение и возможные ограничения.
3. Определи, доступны ли исходные файлы для локального сохранения. Если нет, не маскируй внешнюю ссылку под локальный файл.
4. Если референсов нет или они не покрывают заявленные визуальные ориентиры, запроси у пользователя необходимые изображения или явное разрешение завершить гайд без них.
5. После определения целевой папки скопируй разрешённые локальные файлы рядом с гайдом по правилам проекта.
6. Проверь файл, относительную ссылку и соответствие подписи его реальному содержанию.

## Выход

Таблица референсов в гайде: идентификатор, назначение, локальный путь и источник. При отсутствии материалов — BLOCKED с точным запросом пользователю.
