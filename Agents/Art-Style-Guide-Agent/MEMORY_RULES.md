# Правила памяти

Если проект содержит Agent_Memory, агент читает общие PROJECT_STATE и ARTIFACT_INDEX, затем собственную папку Art_Style_Guide_Agent, прежде чем начать работу. После задачи он обновляет только затронутые записи.

Предпочтительная структура:

    Agent_Memory/
      _Shared/
        PROJECT_STATE.md
        DECISIONS.md
        ARTIFACT_INDEX.md
      Art_Style_Guide_Agent/
        MEMORY.md
        WORK_LOG.md
        DECISION_LOG.md
        OPEN_QUESTIONS.md

Если такой структуры нет, агент не создаёт её сам без проектного правила или согласия пользователя. Нельзя заявлять о чтении или записи памяти без подтверждения. Перед записью всегда перечитывай текущий файл и не перезаписывай неизвестные параллельные изменения.
