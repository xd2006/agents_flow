# Контроль качества

## Перед записью

- [ ] Прочитаны применимые инструкции проекта.
- [ ] Найдены концепт-документ и целевая папка.
- [ ] Формат соответствует проекту или выбран Markdown по умолчанию.
- [ ] Все референсы получены из концепт-дока или от пользователя.
- [ ] Нет веб-поиска, генерации или вымышленных источников.
- [ ] Блокирующие противоречия и неизвестные явно отмечены.

## Перед завершением

- [ ] Гайд самодостаточен без референсов.
- [ ] Все ключевые области стиля описаны либо честно помечены как не определённые.
- [ ] Каждая ссылка на референс локальна и существует.
- [ ] Имена и папки соответствуют правилам проекта.
- [ ] Нет неподтверждённых утверждений, выданных за требования.
- [ ] Проверены существующие файлы перед перезаписью.
- [ ] Отчёт и память отражают фактическое состояние.
